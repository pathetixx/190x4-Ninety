Ninety — 190X4 VPN
===================

Лицензия MIT (Copyright © 2026 pathetixx · 190x4.pw)

Программа распространяется бесплатно. Исходный код открыт:
https://github.com/pathetixx/190x4-Ninety

КРАТКО О ТОМ, ЧТО ВЫ УСТАНАВЛИВАЕТЕ:

  •  Ninety.exe — интерфейс и управляющая часть клиента.
  •  sing-box.exe — основной сетевой движок.
  •  xray.exe — движок для подключений XHTTP.
  •  naive.exe и trusttunnel_client.exe — локальные клиенты-мосты для
     NaiveProxy и TrustTunnel.
  •  wintun.dll — компонент виртуального сетевого адаптера для режима VPN · TUN.
  •  winws.exe, WinDivert64.sys и Monkey64.sys — компоненты обхода DPI.

Ninety не устанавливает постоянно работающую собственную Windows-службу.
Системные права запрашиваются только для операций, которым они необходимы:
режима VPN · TUN, обхода DPI и очистки соответствующих драйверов.

ЧТО ОТПРАВЛЯЕТСЯ В ИНТЕРНЕТ:

  •  Подписки загружаются с адресов, которые добавил пользователь. При включённом
     прямом резервном обновлении запрос может выполняться без VPN.
  •  VPN-трафик передаётся выбранным пользователем серверам и используемым ими
     сетевым посредникам.
  •  Проверка обновлений приложения выполняется через GitLab и GitHub Releases;
     обновления данных обхода DPI — через подписанный канал GitHub Releases.
  •  Проверки региона, доступности и качества соединения обращаются к внешним
     тестовым/IP-сервисам только при использовании соответствующих функций.
  •  Регистрация WARP обращается к API Cloudflare только по команде пользователя.
  •  Ninety не содержит собственной телеметрии, аналитики или рекламы.

СТОРОННИЕ КОМПОНЕНТЫ:

  В состав поставки входят отдельные сторонние исполняемые файлы, библиотеки и
  драйверы. Они распространяются на условиях собственных лицензий их авторов.
  Ссылки на исходный код, версии компонентов и сведения о сборке опубликованы в
  репозитории Ninety и workflow выпуска.

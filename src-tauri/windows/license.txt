WHAT YOU ARE INSTALLING:

  •  Ninety.exe — the application interface and controller.
  •  sing-box.exe — the primary networking engine.
  •  xray.exe — the engine used for XHTTP connections.
  •  naive.exe and trusttunnel_client.exe — local protocol bridges for
     NaiveProxy and TrustTunnel.
  •  wintun.dll — the virtual network adapter component for VPN · TUN mode.
  •  winws.exe, WinDivert64.sys and Monkey64.sys — DPI-bypass components.

Ninety does not install its own permanently running Windows service.
Elevated access is requested only for operations that require it: VPN · TUN,
DPI bypass and cleanup of the corresponding drivers.

WHAT IS SENT TO THE INTERNET:

  •  Subscriptions are fetched from addresses added by the user. When direct
     fallback refresh is enabled, the request may be made without the VPN.
  •  VPN traffic is sent to user-selected servers and their network providers.
  •  App updates are checked through GitLab and GitHub Releases; DPI data is
     updated through a signed GitHub Releases channel.
  •  Region, availability and connection-quality checks contact external test
     or IP services only when the corresponding features are used.
  •  WARP registration contacts the Cloudflare API only on explicit request.
  •  Ninety contains no first-party telemetry, analytics or advertising.

ЧТО ВЫ УСТАНАВЛИВАЕТЕ:

  •  Ninety.exe — интерфейс и управляющая часть клиента.
  •  sing-box.exe — основной сетевой движок.
  •  xray.exe — движок для подключений XHTTP.
  •  naive.exe и trusttunnel_client.exe — локальные клиенты-мосты для
     NaiveProxy и TrustTunnel.
  •  wintun.dll — компонент виртуального сетевого адаптера для VPN · TUN.
  •  winws.exe, WinDivert64.sys и Monkey64.sys — компоненты обхода DPI.

Ninety не устанавливает постоянно работающую собственную Windows-службу.
Системные права запрашиваются только для операций, которым они необходимы:
режима VPN · TUN, обхода DPI и очистки соответствующих драйверов.

ЧТО ОТПРАВЛЯЕТСЯ В ИНТЕРНЕТ:

  •  Подписки загружаются с адресов, которые добавил пользователь. При включённом
     прямом резервном обновлении запрос может выполняться без VPN.
  •  VPN-трафик передаётся выбранным пользователем серверам и используемым ими
     сетевым посредникам.
  •  Проверка обновлений выполняется через GitLab и GitHub Releases; обновления
     данных DPI — через подписанный канал GitHub Releases.
  •  Проверки региона, доступности и качества соединения обращаются к внешним
     тестовым/IP-сервисам только при использовании соответствующих функций.
  •  Регистрация WARP обращается к API Cloudflare только по команде пользователя.
  •  Ninety не содержит собственной телеметрии, аналитики или рекламы.

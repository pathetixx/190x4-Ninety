# winget manifests

Manifests for the `190x4.Ninety` package in [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs).
The folder layout mirrors that repository: copy `manifests/1/190x4.Ninety/<version>` into a
winget-pkgs fork and open a pull request.

For a new release, copy the previous version folder and update `PackageVersion`,
`InstallerUrl`, `InstallerSha256` (the `digest` of `Ninety_X.Y.Z_x64-setup.exe` in the GitHub
release), `ReleaseDate` and `ReleaseNotesUrl`.

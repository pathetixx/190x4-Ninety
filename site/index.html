A VPN client for Windows

Ninety is a client, not a service

A subscription or a single config turns into a working connection: Ninety picks a fast server, watches the speed, gets around blocking and shows you exactly where the connection breaks when something goes wrong. sing-box runs underneath, but there are no engines to choose and no configs to edit by hand.

Features

You bring the servers — Ninety handles the rest

01

Windows modes

Proxy for selected apps, a system proxy, or a full VPN for the whole computer. Administrator rights are requested only where the mode cannot work without them.

02

Sources

A subscription link, a single config, a ready-made sing-box or Xray config, a WireGuard/AmneziaWG file or a TrustTunnel endpoint. A link can simply be pasted from the clipboard.

03

Protocols

VLESS, VMess, Trojan, Shadowsocks, Hysteria2, Hysteria, TUIC, AnyTLS, SOCKS, NaiveProxy, TrustTunnel, WireGuard/AmneziaWG and WARP — all in one app, with no engine to pick by hand.

04

Routing

The local network stays outside the tunnel, regional rules come ready, and your own rules work by site, address or program. A single rule can send its traffic to a chosen server or to WARP.

05

Blocking bypass

Built-in bypass for services that will not open directly. It works even with the VPN off, and the address of the active server is added to the exclusions on its own.

06

Diagnostics

Every service is checked twice — directly and through Ninety — so you can see who is actually in the way: the provider, the service or the server. The trace, leak checks and a feed of failures are right there.

07

Channel quality

Ninety measures real speed, not just ping. When the channel is being throttled it changes the server or turns on masking by itself, and says what it did.

08

Network protection

The kill switch cuts traffic if the tunnel drops. On an open Wi-Fi outside your trusted list Ninety turns the VPN on by itself and puts the previous mode back once the network is safe again.

09

Interface

Tray controls, in-app updates, session restore after an update, themes and 15 languages.

Safety notes

Powerful networking tools need honest limits

Not anonymity

Privacy depends on the server, provider, profile and Windows environment. Ninety helps manage the connection, but it does not change that trust model.

Do not publish secrets

Public issues must not include subscription URLs, UUIDs, tokens, private keys, WARP data or full exported configs.

System modes are visible

TUN, kill switch and DPI compatibility can change Windows networking state. Enable them deliberately and check settings before reporting bugs.

Windows networking client

One interface for profiles, modes and diagnostics

Ninety brings subscriptions, standalone profiles, WARP, TUN, routing, logs and auto-updates into one desktop client. The project focuses on predictable connection state, honest limitations and careful Windows network handling.

Features

A networking client without the noise

01

Windows modes

Local proxy, system proxy, VPN · TUN and WARP-only. Elevated mode is used only when the selected mode actually needs it.

02

Sources

Subscriptions, standalone links, TrustTunnel endpoint files and WireGuard/AmneziaWG .conf files. Clipboard import and deep links stay in one user flow.

03

Routing

LAN bypass, regional rules, custom domain/IP/process rules and a separate live connections monitor.

04

Channel quality

Delay checks, throughput watching, node re-tests, recovery hints and useful logs instead of a vague connected label.

05

Sidecar engines

sing-box remains the central router, while XHTTP, NaiveProxy and TrustTunnel are attached through local bridges when a profile requires them.

06

Desktop UX

Tray control, post-update session restore, themes, onboarding, localizations and cautious defaults for logs and runtime configs.

Safety notes

Powerful networking tools need honest limits

Not anonymity

Privacy depends on the server, provider, profile and Windows environment. Ninety helps manage the connection, but it does not change that trust model.

Do not publish secrets

Public issues must not include subscription URLs, UUIDs, tokens, private keys, WARP data or full exported configs.

System modes are visible

TUN, kill switch and DPI compatibility can change Windows networking state. Enable them deliberately and check settings before reporting bugs.

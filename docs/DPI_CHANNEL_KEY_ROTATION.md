# Ротация ключа DPI-канала

DPI-канал подписывается отдельным minisign-ключом. Клиент временно принимает
сначала новый dedicated key, затем legacy OTA key, чтобы уже опубликованный
`dpi-channel` продолжал работать до ротации.

1. Выпустить версию приложения с dual trust для нового и legacy ключей.
2. Убедиться, что эту версию установила достаточная доля пользователей.
3. Вручную запустить `DPI channel (Flowseal sync)` только с проверенным upstream tag
   и reviewed SHA-256 архива.
4. Убедиться, что опубликованный bundle подписан dedicated DPI key.
5. В следующем отдельном релизе приложения удалить legacy trust из `dpi.rs`.

До шага 3 нельзя публиковать новый DPI-канал: опубликованный legacy bundle нужен
клиентам предыдущих версий.
